# Community docs

This is a set of documents intended to help start off a professional developer community on the right foot. The Code of Conduct is based of the one used by [Reactiflux](https://reactiflux.com/conduct), and the Incident Response is based off the one used by the [Rands Leadership Slack](https://randsinrepose.com/welcome-to-rands-leadership-slack/). I'm also currently using it as a dumping ground for some research on e.g. codes of conduct and other constitutional documents.

# React Ecosystem Community

The React ecosystem has always been larger than any 1 of its constituent communities. This grouping of documents attempts to provide a measure of standardization between these disparate and decentralized spaces, ensuring that if someone attends a "React community event" or enters a "React community space", they can be confident that the space, the attendees, and the organizers share an understanding of how to bring people together safely.

## For Organizers

These documents are intended to be a resource for you as you navigate the complexities of dealing with conflict in community spaces,.

## For Community Members

These documents will help you better understand the social norms, minimum expectations for behavior, and accountability processes.
