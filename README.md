# Community docs template

This is a set of documents intended to help start off a professional developer community on the right foot. The Code of Conduct is based of the one used by [Reactiflux](https://reactiflux.com/conduct), and the Incident Response is based off the one used by the [Rands Leadership Slack](https://randsinrepose.com/welcome-to-rands-leadership-slack/)

## Using this repo

Create a fork under the organization you want to create a community for.

- Update the channel guidelines and how-to sections.
- Review and update the `CODE_OF_CONDUCT.md` and `INCIDENT_RESPONSE.md` to reflect your community's values and processes. Prefer to phrase them in positive terms — think in terms of what you want to see, rather than what you want to prohibit.
- Delete everything from the `---` and up.
